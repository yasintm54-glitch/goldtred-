# GoldTrend (نسخه موبایل / اندروید PWA)

اپ تحلیل طلا و ارز ایران — قابل نصب روی گوشی با Chrome و انتشار روی **GitHub Pages**.

> این APK فروشگاهی نیست؛ Progressive Web App است (نصب از مرورگر روی صفحهٔ اصلی).

## انتشار روی GitHub Pages

1. یک ریپوی جدید بساز (مثلاً `GoldTrend`).
2. **محتوای همین پوشه** را در ریشهٔ ریپو push کن (`index.html` باید در root باشد).
3. Settings → Pages → Source: **Deploy from a branch** → branch `main` → folder `/ (root)`.
4. بعد از ۱–۲ دقیقه باز کن:
   `https://USER.github.io/GoldTrend/`
5. در Chrome اندروید: منو → **Install app** / Add to Home screen.

اگر ریپو همان `username.github.io` است، فایل‌ها را مستقیم در root همان ریپو بگذار.
